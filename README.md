# GEMS


## Как играть

- Кликните на один квадрат, затем на соседний — они поменяются местами.
- Если после обмена образуется связная группа из **3 и более квадратов одного цвета** (горизонтально, вертикально, L/T-формы — любая связность), они уничтожаются.
- Оставшиеся квадраты падают вниз; сверху добавляются новые. Цепочки проверяются повторно.
- При уничтожении квадрата с небольшой вероятностью выпадает **бонус** в радиусе 3 клеток:
  - 🟡 **Перекраска** — целевой квадрат и 2 несоседних с ним квадрата в радиусе окрашиваются в цвет исходного квадрата.
  - 🟠 **Бомба** — уничтожает 5 случайных квадратов (включая целевой). Вспышка оранжевого цвета.

## Сборка

### Требования
- CMake ≥ 3.16
- Компилятор с поддержкой C++17 (GCC 9+, Clang 9+, MSVC 2019+)
- Git (для загрузки SFML через FetchContent)
### Windows (MSVC)
```powershell
cmake -B build
cmake --build build --config Release
.\build\Release\GEMS.exe
```
